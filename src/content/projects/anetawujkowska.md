# anetawujkowska.pl

Strona osobista dla eksperta finansowego z Ostrowa Mazowieckiego, specjalizującego się w kredytach hipotecznych i finansowaniu nieruchomości.

## Zakres prac:

- Projekt i wdrożenie strony w Astro 5
- SSR z Cloudflare Pages (edge rendering)
- Responsywny design (mobile-first) z natywnym CSS
- Optymalizacja wydajności i Core Web Vitals
- Sitemap i SEO
