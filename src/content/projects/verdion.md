# Verdion

Strona firmowa zbudowana na nowoczesnym stacku WordPress: Roots/Bedrock jako boilerplate oraz autorski motyw Sage z Tailwind CSS v4. Projekt w fazie aktywnej implementacji.

## Zakres prac:

- Konfiguracja środowiska Roots/Bedrock (Composer, PHP 8.4)
- Autorski motyw blokowy na bazie Sage z Tailwind CSS v4
- Automatyczny deployment przez Deployer
- Środowisko lokalne DDEV
